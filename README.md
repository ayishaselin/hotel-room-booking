# Hotel Room Booking

A simple and responsive hotel room booking interface built with HTML, CSS, and JavaScript.

## Live Demo
[https://hotel-booking-selin.netlify.app](https://hotel-booking-selin.netlify.app)
https://hotel-booking-selin.netlify.app
https://github.com/ayishaselin/hotel-room-booking.git

## Tech Stack

- HTML5
- CSS3
- JavaScript 

## Features

- Select check-in and check-out dates
- Validate date ranges
- Calculate number of nights
- Calculate total booking price
- Display available rooms
- Select and deselect rooms
- Filter rooms by room type
- Filter rooms by guest capacity
- Display booking summary inside the selected room
- Responsive layout for desktop and mobile


## How to Run

1. Clone or download the repository.
2. Open the project in a code editor.
3. Run `index.html` using a local development server.



## Project Structure

- `index.html` — page structure
- `css/style.css` — styling and responsive layout
- `js/app.js` — application logic and event handling
- `js/data/rooms.js` — sample room data
- `js/utils/dateUtils.js` — date-related functions
- `js/utils/bookingUtils.js` — booking price calculation
- `js/utils/validation.js` — input validation
- `js/ui/roomRenderer.js` — room and booking summary rendering
